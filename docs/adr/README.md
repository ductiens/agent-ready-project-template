# Architecture Decision Records

Use an ADR for durable technical decisions that future contributors and agents must not silently reverse.

Create files named:

```text
NNNN-short-decision-title.md
```

Template:

```markdown
# Decision title

## Status

Proposed | Accepted | Superseded | Deprecated

## Context

What problem, constraints, and alternatives led to this decision?

## Decision

What was chosen?

## Consequences

What becomes easier, harder, required, or prohibited?
```

Do not use ADRs for temporary task progress or routine implementation details.
